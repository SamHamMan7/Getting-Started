# Running Total

Read N, then N integers on the next line. After each value, print the sum of everything read so far. Print the N running totals on one line, separated by spaces.

1 ≤ N ≤ 10000. Integers: -10^9 to 10^9.

Use a 64-bit integer for the running sum in C, C++, and Java.

Time limit: 2 seconds per test.

Example Input:
```text
5
3 -2 4 1 -6
```

Example Output:
```text
3 1 5 6 0
```
