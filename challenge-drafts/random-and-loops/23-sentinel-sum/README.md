# Sentinel Sum

Read integers one per line. Stop when you read the first `0`. Print the sum of all values before that `0`; do not include the `0`.

There can be from 0 to 10000 values before the sentinel. Each nonzero value is between -10^9 and 10^9. The input always contains a terminating `0`.

Use a 64-bit integer for the sum in C, C++, and Java.

Time limit: 2 seconds per test.

Example Input:
```text
5
-2
8
0
```

Example Output:
```text
11
```
