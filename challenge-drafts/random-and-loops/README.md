# Randomization and Loop Challenge Drafts

These challenge drafts follow the short format used by the existing Getting Started assignments. They are kept outside `assignments/` until the grader/reference solutions are updated for them.

Suggested order:

1. `18-roll-a-six` — random-number library + `while` loop
2. `19-shuffle-sum` — shuffling + `for` loop
3. `20-random-hunt` — random choice + loop-until-condition
4. `21-running-total` — accumulator loop
5. `22-times-table` — nested loops
6. `23-sentinel-sum` — sentinel-controlled loop

For the randomization exercises, the final output is deterministic even though the program must use randomness. This keeps them compatible with the repository's exact-output grading model.
