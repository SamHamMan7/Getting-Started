# Times Table

Read N. Print an N by N multiplication table. Row i contains `i × 1`, `i × 2`, ..., `i × N`, with spaces between values.

Use a loop inside another loop.

1 ≤ N ≤ 50.

Time limit: 2 seconds per test.

Example Input:
```text
4
```

Example Output:
```text
1 2 3 4
2 4 6 8
3 6 9 12
4 8 12 16
```
